# Dengue Dashboard - Preprint

This repository contains the LaTeX source code and supplementary materials for the "Sri Lanka Dengue Dashboard" preprint.

## Overview

This project presents a comprehensive dashboard system for dengue disease monitoring and visualization. The preprint documents the design, implementation, and evaluation of this dashboard system.
